## [Unreleased] ⚪

### Added
- **SEO 미리보기** — 설정 › SEO 카드 맨 위에 검색 결과·SNS 카드 실시간 미리보기. 대상은 홈 / 글 상세 2-way. 길이 미터는 폭 단위(한글 2)로 세고, 잘리는 자리를 그대로 보여준다.
- **링크 프리뷰 카드** — 본문에 URL만 한 줄로 두면 도메인·제목·설명 카드로 펼쳐진다. 메타는 발행 시점에 서버가 읽은 OG 태그 캐시. OG가 없거나 크롤이 막힌 주소는 도메인 + 경로 한 줄로 축소된다.
- **내부 글 카드** — `/posts/slug` 한 줄이면 카테고리·날짜·요약을 붙인 카드. 없는 slug는 점선 박스로 표시해 오타를 발행 전에 잡는다.
- **문장 안 자동 링크** — 본문 중간에 그대로 적은 `https://…`도 링크로 렌더된다.
- Studio 툴바 `↗` 버튼 — 커서 자리에 링크 카드 한 줄을 넣는다. 선택한 텍스트가 URL이면 그걸 쓴다.
- `MARKDOWN.html`에 §08 링크 프리뷰 섹션 추가 (이후 섹션 번호 밀림).
- **시리즈 정렬 토글** — `/series`에 `최근 연재순` / `생성순` 2-way. 기본값은 최근 연재순.
- **시리즈 카드 날짜 표기** — 진행 바 위에 `최근 연재` · `생성` 두 줄. 현재 정렬 기준이 되는 쪽이 진하게 들어온다. 글이 없는 시리즈는 `아직 없음`.
- **반응형 레이아웃 전면 적용** — 모든 페이지가 모바일(≤760px)·태블릿(≤1000px)·데스크톱에서 각각 성립한다. 가로 스크롤 0.
- **모바일 헤더 네비 시트** — 좁은 화면에서 Posts·Series·Linkroll·About이 `☰` 시트로 접힌다. 검색은 아이콘만 남고 계정 pill은 유지.
- **Studio 편집/미리보기 탭** — 좁은 화면에서 2단 편집기를 탭으로 전환. 데스크톱은 기존 2단 그대로.
- 관리자 표(초안 목록)는 좁은 화면에서 가로 스크롤 — 열을 접어 관계를 잃지 않는다.
- 카테고리 사이드바·설정 사이드 네비가 좁은 화면에서 가로 스크롤 스트립으로 전환.
- 터치 기기에서 **hover로 숨겨져 있던 조작 버튼이 항상 보인다** — 설정 카테고리 행(위/아래·편집·삭제·＋서브), Linkroll 수정/삭제.
- **보기 기준 tweak** — `방문자` / `관리자` 2-way. 방문자로 보면 Studio·Admin·Stats·Settings가 로그인 화면으로 대체된다(서버가 막는 동작을 시안에서도 그대로). 로그인 폼은 원래 가려던 곳을 기억했다가 그리로 보낸다.
- **인터랙티브 아바타** — 헤더·작성자 줄의 아바타가 커서를 따라보고(검은자 안 흰 점만 이동), 누르면 표정이 바뀐다(smile / sleepy / wow / proud / sulk). 연타하면 흔들리고 8연타는 미니 아바타가 쏟아진다. 홈 링크에서 분리 — 눌러도 이동하지 않는다.
- **계정 드롭다운 (AdminMenu)** — 헤더 우측에 로그인 계정 핸들 pill. 새 글 / 대시보드 / 통계 / 설정 / 로그아웃.
- `/login` — Studio·Admin 진입용 로그인 페이지. 공개 가입 없음.
- `/admin/stats` — 통계 페이지. 방문자·페이지뷰·세션·이탈률 카드, 일별 페이지뷰 SVG 차트(7일/30일), Top Pages · Referrers · Events.
- **시리즈 네비게이션 2종** — 글 상단 `SeriesBanner`(STEP n / N), 본문 하단 `SeriesStepNav`(이전/다음 단계 카드 + 전체 회차 rail, 미발행 회차는 점선 슬롯).
- **좋아요** — 본문 하단 익명 좋아요. 누른 사실은 브라우저가 기억한다.
- **조회수** — 작성자 줄에 `N views`.
- **홈 Trending** — 최근 7일 조회수 상위 5편. 집계가 비면 섹션이 나오지 않는다.
- **LeadFigure** — 홈 Featured 리드 그림 3단 폴백: 썸네일 > 시리즈 진행 인디케이터 > 카테고리·태그 타이포(slug 해시 색조).
- **Studio 수정 이력** — 툴바 `이력` 버튼 + 패널. 제목·본문·분류만 되돌리고 발행 상태·slug는 유지.
- **Studio frontmatter 확장** — `summary`, `series`(회차 슬롯 선택 + 새 시리즈 인라인 생성), `thumbnail`(대표 이미지).
- **Studio 이미지 삽입** — 툴바 `▣ 이미지` 버튼.
- `ToastBanner` — 화면 우하단 고정 상태 배너. Studio와 이메일 복사가 공유.
- 공용 마크다운 파서 (`markdown.jsx`) — Studio 미리보기와 상세 페이지가 같은 문법을 공유.
- 마크다운 문법 — H1~H4, ` ```lang:filename ` 코드 블록, GitHub 스타일 callout (`> [!INFO|WARNING|TIP|NOTE] 제목` + 멀티라인), `- ` / `1. ` 리스트, `**굵게**` / `*기울임*` / `` `코드` ``, `[텍스트](url)`, `![alt](url)`, `---` 수평선.
- Studio 에디터 툴바 동작 — 버튼 클릭 시 textarea 커서 위치에 마크다운 마커 삽입. 선택 영역이 있으면 그 텍스트를 감쌈.
- Studio 에디터 하단에 **마크다운 문법** 펼침 시트.

### Changed
- 시리즈 카드 높이가 그리드 전체에서 균일해졌다 — 제목·2줄 · 설명·2줄 클램프 + `grid-auto-rows: 1fr`. 설명 길이가 카드 크기를 바꾸던 문제.
- 페이지 좌우 여백이 고정 32px에서 화면 폭에 따라 32/22/16px로 조절.
- 큰 제목(Hero·페이지 h1)이 `clamp()` 기반 가변 크기로 — 모바일에서 줄이 깨지지 않는다.
- 인라인 코드가 더 이상 `nowrap`이 아니다 — 긴 설정 키가 화면을 밀어내던 원인.
- 좁은 화면 입력 필드가 16px — 그 미만이면 iOS가 포커스 때 화면을 확대해버린다.
- 설정 화면 버튼 최소 높이 40px, 아이콘 버튼 34px — 터치로 누를 수 있는 크기.
- 설정 저장 바가 모바일에서 세로 full-width로.
- 아바타 색상 선택 줄이 좁은 화면에서 줄바꿈.
- 헤더 브랜드가 `동` 사각 타일에서 아바타로 교체.
- 헤더 관리자 클러스터(`＋ 새 글` · `▣` · `⚙`) 제거 — 계정 드롭다운으로 통합. 글 단위 액션은 AdminBar에 그대로 남는다.
- 아바타 배경 세이지 → 슬레이트 블루. 세이지가 시리즈 색·성공 톤과 겹쳐 상태 표시로 오독됐다.
- 파비콘을 아바타 축소판에서 워드마크 타일(다크 배경 + 올리브 세리프 `D` + 밑줄 바)로 교체. 16px에서 얼굴보다 글자가 읽힌다.
- 푸터 Email이 `mailto:` 링크에서 **클릭 복사**로 변경. 메일 클라이언트가 없는 방문자가 주소를 알 방법이 없던 문제. 복사 실패 시 토스트에 주소를 노출.
- 홈 Hero 소개 문구를 현재 관심사로 교체 — Spring · Oracle · 분산 서비스 공통 계층 설계 · AI.
- 시간순 prev/next에 `시간순 글 탐색` 라벨 추가 — 시리즈 네비게이션과 구분.
- 분석 도구 Plausible → Umami. 공유 링크를 읽어 통계를 사이트 안에서 본다.
- 사이트 문구를 실제 설정값에 맞춤 — `백엔드 노트` → `개발 노트`, 저작권 `© 2026 Dong-Ding · 개발 노트`, canonical `blog.dongding.dev`.
- /settings SEO 카드를 실제 필드로 교체 — 업로드형 `기본 OG 이미지` 제거(OG는 텍스트로 그려진다), `짧은 제목` · `저작권 표기` · `언어` · `locale` · OG 헤드라인/태그라인/라벨 추가.
- /settings `발행 설정` → `에디터`. 남은 항목은 자동저장 간격과 새 댓글 알림뿐.
- /admin 통계 카드 `RSS 구독자` → `총 조회수`.
- About 소개·경력·관심사를 실제 About 페이지에 맞춤 — `5년차 · JPA · DB internals` → `2년차 · Oracle · 분산 서비스 공통 계층 · AI 활용`. 가상 경력 3줄을 실제 1줄로.
- PRD 표지를 본문과 일치시킴 — 제목 `백엔드 노트, 다시 짓다` → `개발 노트, 다시 짓다`, 버전 `2.0` → `v1.3.0 (작업 중)`, 상태·날짜·pill을 현재 로드맵 기준으로. §01 개요의 연차도 정정.
- Studio 미리보기 파서가 임시 규칙에서 새 공용 파서로 교체.
- `>` 기호는 callout 전용 — 일반 인용문(blockquote)은 지원하지 않음.
- /settings 아바타 행 — 기본값이 이미지 마크. 색상 스와치를 누르면 이니셜 아바타로 전환된다.
- 아바타 헤어 재작업 — 두상 밖으로 나온 볼륨 + 갈라진 앞머리. 옆머리와 두상 사이 흰 틈 제거, 먹색 → 갈색.

### Removed
- **RSS 일체 제거** — 구현되지 않은 기능이라 시안에서만 살아 있었다. 푸터·About의 RSS 링크, /settings의 `RSS 피드 노출`·`RSS 글 개수`, /admin의 `RSS 구독자` 카드, PRD의 `/feed.xml`·RSS 구독자 지표.
- /settings에서 구현되지 않은 필드 제거 — X(Twitter) · LinkedIn · 초안 공개 범위 · 데이터 카드(Markdown ZIP · 구독자 CSV · 블로그 비공개 전환).
- 초기 와이어프레임 일체 (`wireframes.html` · `wireframe-*.jsx` · `design-canvas.jsx`) — hi-fi로 넘어온 뒤 참조되지 않음.
- 파비콘 후보 시트 (`favicon-options.html`)와 후보 SVG 10종 — 마크 확정.
- 아바타·파비콘 확인 시트 (`assets-preview.html`), 작업 중 캡처 (`screenshots/`).

## [1.2.1] — 2026-04-27 ✅ Deployed

> Released: 2026-04-27 · 카테고리 관리 · 파괴적 액션 안전성

### Added
- Studio frontmatter에 **공개 범위** 필드 — 발행 / 비공개 / 초안 3-way 세그먼트. 활성 옵션은 surface + shadow로 들어올림, 아래에 보조 설명 한 줄. 비공개는 "URL 알아도 안 보임".
- `/settings`에 **카테고리 관리** 섹션 — 대분류 + 서브카테고리 트리, 인라인 rename(이름·ID·설명), 순서 변경(↑↓), 추가/삭제, 글 매핑된 카테고리 삭제 시 2단계 컨펌. 사이드 nav에 `카테고리` 진입점.
- 글 상세 `AdminBar`에 **삭제 컨펌 모달** (`ConfirmDialog`) — backdrop blur + 카드형 다이얼로그, danger 톤(brick red 글리프 + 버튼). ESC 취소 / Enter 확인 / 바깥 클릭 취소.
- `ConfirmDialog` 컴포넌트 신규 — `tone: danger | warning | info` 3 변종, `title` · `body` · `meta`(slug 등 식별 블록) · 버튼 라벨 prop. 시리즈/링크롤 삭제에서도 재사용 예정.
- 복제 / 삭제 후 인라인 토스트 (`AdminToast`) — AdminBar 우하단에 2.4초 부유, ok(올리브) / warn(앰버) 톤.

### Changed
- AdminBar 삭제 인터랙션을 인라인 "정말?"에서 모달 컨펌으로 격상. 삭제 호버 시 brick red 보더 + 옅은 틴트 배경.
- `ConfirmDialog` 안전성 패스 — Enter 자동 확정 제거(Esc만 유지), 확정 버튼 자동 포커스 제거(카드 자체에 포커스), 양쪽 버튼의 `esc`/`↵` 키 힌트 라벨 제거. 위험 액션은 의식적 클릭을 거치도록.
- 글 상세 삭제 컨펌 라벨을 더 구체적으로: `삭제` → `이 글 삭제`, `취소` → `그만두기`. 본문 안내는 "수정에서 공개 범위를 비공개로"로 정확히 가리키도록 다듬음.
- CHANGELOG 버저닝을 SemVer로 전환. 각 버전에 배포 상태(`✅`/`🟡`/`⚪`) + `Released` 일자 표기.

## [1.2.0] — 2026-04-27 ✅ Deployed

> Released: 2026-04-27 · Studio·관리자·시리즈·링크롤 본격화

### Added
- Studio 에디터에 `slug` 필드 — `/posts/` 프리픽스 + 자동 생성 버튼(↻), 제목에서 kebab-case 변환, 수동 편집 가능.
- 헤더 관리자 클러스터에 `⚙` 설정 아이콘 — `/settings` 라우팅 진입점. 호버 시 60° 회전.
- Series 관리 — `+ 새 시리즈` 버튼(헤더), 제목/ID/편수/설명/테마 컬러 폼 에디터, 카드 호버 시 수정/순서 변경/삭제 플로팅 액션.
- Linkroll 관리 — `+ 링크 추가` 버튼(헤더), URL/제목/출처/태그/메모 폼, 로우 호버 시 수정/삭제 액션.
- 헤더 네비게이션에 `Series` · `Linkroll` 추가.
- 관리자 모드 (`isAdmin` tweak, 로컬만) — 헤더 우측 `＋ 새 글` + `▣` 대시보드, 포스트 상세 AdminBar (수정/복제/삭제).
- 댓글(Giscus) 시안 — 반응 row, 쓰기/미리보기 탭 컴포저, 로그인 프롬프트.

### Changed
- 인라인 코드(`IC`) 디자인 강화. 회색 박스 대신 따뜻한 앰버 틴트 배경 + 진한 brown 텍스트로 본문에서 즉시 식별. 다크 테마는 머스타드 톤. `whiteSpace: nowrap`으로 식별자가 줄 끝에서 깨지지 않게.
- Admin 헤더에 "설정" CTA 추가. 한국어 라벨이 좁은 flex 컨테이너에서 줄바꿈되지 않도록 `whiteSpace: nowrap` 일괄 적용.

## [1.1.1] — 2026-04-27 ✅ Deployed

> Released: 2026-04-27 · 디테일 정돈
